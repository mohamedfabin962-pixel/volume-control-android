# Volume Control Android

A simple native Android utility that provides quick access to the device's volume controls when the physical volume button is unavailable or inconvenient to use.

## Features

- Floating edge handle
- Works over other apps
- Opens the native Android volume control panel
- Controls media volume through Android's system UI
- Automatically restores the floating handle after device reboot
- Lightweight — no backend, database, or internet connection required

## Tech Stack

- Kotlin
- Android
- Jetpack Compose
- Android WindowManager
- Android Audio / Volume APIs

## Current Status

The current version has been tested on an Android emulator. Real-device testing is the next phase.
